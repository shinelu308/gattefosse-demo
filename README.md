### 操作

| 按键 | 作用 |
|---|---|
| `←` `→` `PageUp` `PageDown` `空格` | 上／下一幕 |
| `Home` / `End` | 首幕 / 末幕 |
| `F` | 全屏 |
| `Q` | 打开应答口径（客户最可能问的 10 个问题 + 应答稿） |
| `S` | 收起 / 展开左侧目录 |
| `Esc` | 关闭弹层 |

其他：点证据截图可放大（灯箱）；顶部「计时」是正计时秒表，落后计划 2 分钟会变黄；打印时会自动展开全部 11 幕。

## 二、社媒模块可交互原型（`prototype.html`）

6 个视图，全部可点：

- **内容工厂** —— 4 步流程 + 5 类内容源 + 平台卡 + 生成动画 + 草稿四级校验
- **发布任务** —— 含真实失败码示例（`40164`、`COMPLIANCE_BLOCKED`）
- **渠道能力** —— 7 个平台的三级梯队（全自动 / 需申请 / 无接口）
- **合规预检** —— 可直接试：输入含「美白」的文案会被一级硬拦
- **GEO** —— 术语唯一真相表 + 法规状态库
- **引擎探测** —— 6 个 AI 搜索引擎的信源偏好

## 四、数据口径说明

界面与讲稿中出现的数字，来源如下：

| 数字 | 含义 | 来源 |
|---|---|---|
| ¥48,000 / ¥128,000 / ¥228,000 | 三档年度报价（含税） | 《嘉法狮中国 · 年度数字资产运营服务方案》GF-CN-DO-2026-01 |
| 25–32 万元 / 年 | 内容营销专员用工成本参照 | 同上 |
| 15–30 万元 / 年 | 品牌代理公司年度数字服务参照 | 同上 |
| 每月 4–6 篇 | 成长版内容运营交付量 | 同上 |
| 20 个工作日 | 领先版年度定制开发额度 | 同上 |
| 4 篇 / 30 天 | 首月承诺交付内容篇数 | 同上 |
